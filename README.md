## Features
### Before the system saves a user's information, it acts like a security guard, checking the data against a strict set of rules.
### Username Validation
Must be short (5 characters or less) and contain an underscore (_).
### Passwords
Must be strong (8+ characters) and use a mix of uppercase letters, numbers, and special characters.
### Cellphone Validation
Must match the standard South African format, starting with +27
